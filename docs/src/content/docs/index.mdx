`lorawan-connection` is a Python library for modelling LoRaWAN devices. Build device
libraries that expose readings, states, and commands, with subscriptions for updates.

You define each device's data and decoding. The shared base classes manage device
collections and listeners. An optional ChirpStack connection supplies live events
and sends commands.

Start with the [quickstart](/lorawan-connection/getting-started/quickstart/) to replay
a SenseCAP sensor reading and see its temperature and humidity values.
