`lorawan-connection` defines the events a network provider sends to a device
library. It has no runtime dependencies.

Feed events into a vendor collection and listen for new device models. Each model
decodes its events and exposes state for your application to read.

```text
Provider: inventory + live events
    → Vendor collection: catalog matching and model lifecycle
        → Device model: decoding and typed state
            → Consumer: application logic or Home Assistant entities
```

## Release scope

Version 0.1 contains event contracts, fixture payloads, collections, and callback
helpers. The SenseCAP implementation is a tested example of a separate library.
ChirpStack connections, QR onboarding, BLE provisioning, and downlink commands are
outside this package's first release.

The Home Assistant guide describes the working Core POC. Its provider API is not
yet part of upstream Home Assistant.
