Define device models that decode readings and send commands. `lorawan-connection`
creates those models from server inventory and routes events to them. Applications
read model attributes and subscribe to updates.

Optional ChirpStack and The Things Stack backends connect to live servers.
The [quickstart](/lorawan-connection/getting-started/quickstart/) replays a SenseCAP
sensor reading without a server.
