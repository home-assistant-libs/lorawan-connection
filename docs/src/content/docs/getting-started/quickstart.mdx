Install the shared library from PyPI:

```sh
pip install lorawan-connection
```

Save the [example library](#example-library)
as `sensecap_lorawan.py`. Save the replay below as `replay.py` in the same directory,
then run it:

```sh
python replay.py
```

The output is:

```text
Device: Greenhouse
temperature=21.4, humidity=31.4
```

The mock connection supplies a device descriptor followed by a captured uplink.
The collection creates the S2101 model, which decodes the reading and notifies its
listener. No server is needed.

## Example library

Save this as `sensecap_lorawan.py` alongside `replay.py`:

<Code code={library} lang="python" title="sensecap_lorawan.py" />

This example follows the [Seeed reference decoders](https://github.com/Seeed-Solution/SenseCAP-Decoder).
It decodes channel-one temperature, humidity, and light records without validating
the two-byte trailer. Tests replay captures from physical S2101 and S2102 devices.
See [captured payloads](/lorawan-connection/patterns/testing/#captured-payloads).
