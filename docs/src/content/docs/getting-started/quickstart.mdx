Install the shared library from PyPI:

```sh
pip install lorawan-connection
```

Save the [example library](#example-library)
as `sensecap_lorawan.py`. Save the replay below as `replay.py` in the same directory,
then run it:

```sh
python replay.py
```

The output is:

```text
Device: Greenhouse
temperature=21.4, humidity=31.4
```

The first event supplies catalog identity. The collection selects and creates the
model, then calls `device_added`. The next event carries the captured uplink.
The model decodes it and notifies its state listener.

The replay supplies a mock connection, so it needs no server.

<Code code={replay} lang="python" title="replay.py" />

The example closes the collection when finished. The collection removes its event subscription.

## Example library

Save this as `sensecap_lorawan.py` alongside `replay.py`:

<Code code={library} lang="python" title="sensecap_lorawan.py" />

This example follows the [Seeed reference decoders](https://github.com/Seeed-Solution/SenseCAP-Decoder).
It decodes channel-one temperature and humidity records, but does not validate the
two-byte trailer. It has been tested with captured payloads and a simulated device,
not physical SenseCAP hardware.

Read [Devices and collections](/lorawan-connection/modelling/overview/) to write
your own models, then [Build a device library](/lorawan-connection/patterns/library/)
to organize them into a package.
